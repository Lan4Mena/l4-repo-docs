# Catálogo de Repositorios

Este catálogo reúne proyectos personales y sus accesos a documentación publicada.

| Sistema / Proyecto | Repositorio | Tipo | Descripción | Documentación publicada | Responsable | Estado |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Portfolio Docs** | [l4-repo-docs](https://github.com/Lan4Mena/l4-repo-docs) | Portal de documentación | Portal personal Docs-as-Code con Jekyll y GitHub Pages. | [Ver documentación](https://lan4mena.github.io/l4-repo-docs/) | Lan4Mena | Activo |

## Reglas

- Agrega únicamente repositorios personales que quieras mostrar en el portafolio.
- La documentación publicada debe apuntar a GitHub Pages u otra URL navegable, no a Markdown crudo.
- Usa los estados `Activo`, `En desarrollo`, `Archivado`, `Deprecado` o `Pendiente de documentación`.
- Actualiza el catálogo cuando cambie el nombre, estado o URL de un proyecto.
