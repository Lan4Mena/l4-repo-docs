# 🔄 Procesos Transversales

Esta sección documenta procesos reutilizables para planificar, implementar, revisar y publicar cambios. A diferencia de `docs-repo/req/`, que define **qué se necesita**, aquí se describe **cómo llevar esos cambios hasta su entrega**.

---

## 📂 Contenido del Directorio

En este directorio encontrarás:

*   **[GitHub Flow del portafolio](github-flow.html):** Flujo estándar para llevar una Historia de Usuario desde `Backlog` hasta `Done` usando ramas, Pull Requests, CI, aprobaciones y documentación.

---

## 🧭 Separación de responsabilidades

*   **`README.md`:** Entrada principal del repositorio; resume el propósito, tecnologías y enlaces clave.
*   **`docs-repo/req/`:** Casos de uso, historias de usuario, criterios de aceptación, reglas y flujos.
*   **`docs-repo/procesos/`:** Forma de trabajo para construir, revisar, integrar y entregar cambios.
*   **`docs-repo/docs/`:** Documentación técnica viva, como arquitectura, despliegue, validación local y decisiones técnicas.
